# План: Рефакторинг микросервисной архитектуры (по заданию)

## Цель
Соответствовать требованиям задания: Maven-модули с независимым запуском на разных портах + Docker Compose.

## Задачи

### 1. Разделить конфигурации сервисов ✅
- `user-service/src/main/resources/application.yml` — port 8080, PostgreSQL, Kafka producer
- `notification-service/src/main/resources/application.yml` — port 8081, Kafka consumer, SMTP

### 2. Docker Compose ✅
- PostgreSQL, Kafka, Zookeeper, Mailpit

### 3. Убрать API Gateway (не требуется по заданию)
- Удалить модуль `api-gateway`
- Убрать Spring Cloud BOM из parent pom
- Убрать module `api-gateway` из parent pom

## Итоговая структура
```
homework-project
├── common-dto       ← общие DTO (UserEvent, OperationType)
├── user-service     ← port 8080, CRUD + Kafka producer
├── notification-service ← port 8081, Kafka consumer + email
└── docker-compose.yml
```

## Verification
1. `mvn clean compile` — 3 модуля собираются
2. Каждый сервис запускается на своём порту
3. Docker Compose поднимает инфраструктуру
